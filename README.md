

Готовий Django-проєкт для сайту грузинського ресторану:

 Меню страв з категоріями (Хінкалі, Хачапурі, Салати, Напої тощо)
 Додавати / редагувати / видаляти страви та позначати їх «в наявності» може
  **тільки адміністратор** через стандартну Django-адмінку (`/admin/`)
  Звичайні відвідувачі сайту можуть лише переглядати меню — без реєстрації
  та без можливості щось змінювати
  Дизайн у грузинському стилі: бордо + золото, орнаментальні розділювачі,
  декоративні шрифти
 Помічник праворуч — плаваюча іконка, яку можна **перетягувати мишкою по
  всьому екрану**. Клік по ній показує підказку "Раджу сьогодні скуштувати"
  з випадковою стравою з тих, що зараз є в наявності

## Встановлення та запуск

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

2. Застосуйте міграції бази даних:
   ```bash
   python manage.py migrate
   ```

3. Створіть акаунт адміністратора:
   ```bash
   python manage.py createsuperuser
   ```
   Введіть логін, e-mail (можна пропустити) та пароль.

4. (Необов'язково) Наповніть сайт прикладовими стравами:
   ```bash
   python seed_data.py
   ```

5. Запустіть сервер розробки:
   ```bash
   python manage.py runserver
   ```




## Розгортання на Render.com

Проєкт підготовлено для Render: Gunicorn запускає Django, WhiteNoise роздає CSS/JS,
а PostgreSQL зберігає меню й акаунти незалежно від перезапусків сервера.

1. Розпакуйте ZIP і завантажте папку проєкту в новий GitHub-репозиторій.
2. На Render натисніть **New + → Blueprint** і підключіть цей GitHub-репозиторій.
3. Render знайде `render.yaml` і створить вебсервіс та PostgreSQL. Підтвердіть створення.
4. Дочекайтеся статусу **Live**, відкрийте адресу `https://...onrender.com`.
5. Щоб створити адміністратора, відкрийте **Shell** вебсервісу на Render і виконайте:
   `python manage.py createsuperuser`
   Після цього адмінка буде доступна за адресою `/admin/`.

Важливо:
- Безкоштовний вебсервіс Render може засинати після періоду без запитів, тому перше відкриття
  може бути повільним. Безкоштовна база Render має обмеження та може мати строк дії — перевірте
  актуальні умови Render перед запуском.
- Завантажені через адмінку медіафайли (наприклад, фото страв) на локальному диску Render
  не є постійним сховищем. Для постійних фото потрібне зовнішнє object storage або окремий
  persistent disk.
- Секретний ключ задається Render через `SECRET_KEY`; не публікуйте його у відкритому коді.
