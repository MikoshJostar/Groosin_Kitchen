# Сакартвело — сайт грузинського ресторану на Django

Готовий Django-проєкт для сайту грузинського ресторану:

- 🍽 Меню страв з категоріями (Хінкалі, Хачапурі, Салати, Напої тощо)
- 🔐 Додавати / редагувати / видаляти страви та позначати їх «в наявності» може
  **тільки адміністратор** через стандартну Django-адмінку (`/admin/`)
- 👀 Звичайні відвідувачі сайту можуть лише переглядати меню — без реєстрації
  та без можливості щось змінювати
- 🎨 Дизайн у грузинському стилі: бордо + золото, орнаментальні розділювачі,
  декоративні шрифти
- 🧙 Помічник праворуч — плаваюча іконка, яку можна **перетягувати мишкою по
  всьому екрану**. Клік по ній показує підказку "Раджу сьогодні скуштувати"
  з випадковою стравою з тих, що зараз є в наявності

## Встановлення та запуск

1. Розпакуйте архів і перейдіть у папку проєкту:
   ```bash
   cd georgian_restaurant
   ```

2. Створіть та активуйте віртуальне середовище (рекомендовано):
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS / Linux:
   source venv/bin/activate
   ```

3. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

4. Застосуйте міграції бази даних:
   ```bash
   python manage.py migrate
   ```

5. Створіть акаунт адміністратора:
   ```bash
   python manage.py createsuperuser
   ```
   Введіть логін, e-mail (можна пропустити) та пароль.

6. (Необов'язково) Наповніть сайт прикладовими стравами:
   ```bash
   python seed_data.py
   ```

7. Запустіть сервер розробки:
   ```bash
   python manage.py runserver
   ```

8. Відкрийте у браузері:
   - Сайт: http://127.0.0.1:8000/
   - Адмінка: http://127.0.0.1:8000/admin/

## Як додати страву (для адміністратора)

1. Увійдіть в `/admin/` під своїм акаунтом суперкористувача.
2. Розділ **Категорії** → додайте категорію (напр. «Супи»), якщо потрібна нова.
3. Розділ **Страви** → «Додати страву +»:
   - назва, опис, ціна, фото (необов'язково)
   - категорія
   - прапорець **«В наявності»** — тільки такі страви показуються у
     рекомендаціях помічника; страви без цього прапорця відображаються на
     сайті з позначкою «Немає в наявності»
   - прапорці «Гостра» / «Вегетаріанська» — просто позначки для гостей

Звичайні відвідувачі сайту (без входу в адмінку) бачать лише сторінку меню і
не мають доступу до форм додавання/редагування — весь функціонал керування
стравами захищений стандартною автентифікацією Django-адмінки.

## Структура проєкту

```
georgian_restaurant/
├── manage.py
├── requirements.txt
├── seed_data.py                # скрипт для наповнення демо-даними
├── georgian_restaurant/         # налаштування проєкту
│   ├── settings.py
│   ├── urls.py
│   └── ...
└── restaurant/                  # застосунок ресторану
    ├── models.py                 # Category, FoodItem
    ├── admin.py                  # адмінка для керування стравами
    ├── views.py
    ├── urls.py
    ├── templates/restaurant/
    │   ├── base.html
    │   ├── home.html
    │   └── _food_card.html
    └── static/restaurant/
        ├── css/style.css        # грузинський дизайн
        └── js/assistant.js      # логіка перетягуваного помічника
```

## Нотатки щодо продакшену

Це базовий проєкт для розробки/демонстрації (`DEBUG = True`, SQLite,
дев-сервер). Перед публікацією в інтернеті варто:

- згенерувати новий `SECRET_KEY` і винести його в змінні середовища;
- вимкнути `DEBUG` та налаштувати `ALLOWED_HOSTS`;
- перейти на PostgreSQL/MySQL;
- налаштувати роздачу статики/медіа через nginx або хмарне сховище;
- запустити через Gunicorn/uWSGI за проксі (nginx/Caddy).
