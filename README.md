

Готовий Django-проєкт для сайту грузинського ресторану:

 Меню страв з категоріями (Хінкалі, Хачапурі, Салати, Напої тощо)
 Додавати / редагувати / видаляти страви та позначати їх «в наявності» може
  **тільки адміністратор** через стандартну Django-адмінку (`/admin/`)
  Звичайні відвідувачі сайту можуть лише переглядати меню — без реєстрації
  та без можливості щось змінювати
  Дизайн у грузинському стилі: бордо + золото, орнаментальні розділювачі,
  декоративні шрифти
 Помічник праворуч — плаваюча іконка, яку можна **перетягувати мишкою по
  всьому екрану**. Клік по ній показує підказку "Раджу сьогодні скуштувати"
  з випадковою стравою з тих, що зараз є в наявності

## Встановлення та запуск

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

2. Застосуйте міграції бази даних:
   ```bash
   python manage.py migrate
   ```

3. Створіть акаунт адміністратора:
   ```bash
   python manage.py createsuperuser
   ```
   Введіть логін, e-mail (можна пропустити) та пароль.

4. (Необов'язково) Наповніть сайт прикладовими стравами:
   ```bash
   python seed_data.py
   ```

5. Запустіть сервер розробки:
   ```bash
   python manage.py runserver
   ```
